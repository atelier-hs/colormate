# 성수 컬러메이트

2026 크리에이티브X성수 축제 참여자를 위한 보조 안내 웹앱 프로토타입입니다. 기존 게임(컬러 어드벤처)은 그대로 두고, 행사장 QR로 여는 안내 도구를 옆에 더합니다.

## 화면

| 파일 | 화면 | 내용 |
| --- | --- | --- |
| `index.html` | 홈 | 결제 전 미리보기, 언어 선택(모든 화면에 유지), 언어 익명 집계 안내 |
| `guide.html` | AI 가이드 | 참여 방법·키트·비용 안내, 미션 단계 힌트(정답 비공개), 실시간 혼잡 답변 |
| `map.html` | 혼잡 지도 | 장소를 누르면 그 장소의 실시간 혼잡도·예측으로 카드 전환, 네이버 지도 연결 |
| `ops.html` | 운영자 대시보드 | 막힘 지점, 언어별 이용, 시간대별 질문과 혼잡 (예시 데이터) |

## 공공데이터 연결

- 서울 실시간 도시데이터(인구) `citydata_ppltn` API를 `api/citydata.js`가 대신 호출합니다.
  브라우저에서 서울시 API(http)를 직접 부르면 차단되기 때문입니다.
- 장소와 도시데이터 지역의 연결은 `assets/app.js`의 `PLACES`에 있습니다.
  `area` 값과 `api/citydata.js`의 `ALLOWED`는 열린데이터광장의 「서울시 주요 121장소 목록」 이름과 정확히 같아야 합니다. 목록에서 확인 후 수정하세요.
- 서버가 없거나(파일을 바로 열었을 때) 키가 없으면 화면에 "예시값"을 표시합니다.
- 축제 기간 데이터를 쌓으려면 `tools/collect.py`(10분 간격 수집, CSV 저장)를 함께 돌리세요.

## 배포 (Vercel)

1. 이 폴더를 GitHub 저장소에 올리고 Vercel에서 Import 합니다. 빌드 설정은 필요 없습니다.
2. Settings → Environment Variables에 등록합니다.
   - `SEOUL_API_KEY`: 서울 열린데이터광장 일반 인증키 (필수, 혼잡도)
   - `ANTHROPIC_API_KEY`: Claude API 키 (선택, AI 가이드 LLM 답변)
   - `CLAUDE_MODEL`: 선택, 기본값 `claude-sonnet-5-5`
3. 배포 후 `/map.html`에서 오른쪽 위 표시가 "실시간"으로 바뀌면 연결된 것입니다.

로컬 확인은 `npx vercel dev`로 하면 `api/` 함수까지 함께 동작합니다. HTML 파일만 열어도 화면은 예시값으로 동작합니다.
